# Private Poker Game V4.4.6

本版针对远程联机测试后的比牌隐私和比牌确认界面做调整。

## 1. 结算界面的手牌公开规则修正

结算时不再因为“最后通过开牌结束”就把所有曾参与本局的玩家牌全部翻开。

现在规则为：

- 自己：始终可以看到自己的三张牌。
- 明弃玩家：所有人可看到其三张牌。
- 最终开牌时仍在场、实际参与开牌的玩家：所有人可看到其三张牌。
- 暗弃玩家：其他人只能看到牌背。
- 之前通过比牌出局的玩家：如果此前没有明弃/开牌公开，其他人只能看到牌背。
- 因此，一个玩家早先盲比失败，即使之后剩余玩家进行了开牌，他的手牌也不会被其他人看到。
- 输家仍整体灰化；赢家正常显示。

## 2. 中途比牌确认界面加入“自己的牌”

仅在比牌没有直接结束整局、需要显示中途比牌结果确认时出现。

每个参与比牌的人只会看到自己的牌，显示规则：

- 盲比成功：显示牌背，继续保持自己的牌未知。
- 盲比失败：向自己显示灰色正面三张牌。
- 已看牌后比牌成功：显示正常正面三张牌。
- 已看牌后比牌失败：显示灰色正面三张牌。

比牌双方不会通过这个界面看到对方的具体手牌。

## 3. 最终比牌规则保持 V4.4.5

如果一次比牌直接决出整局胜负：
- 不再出现单独的比牌确认界面；
- 直接进入统一结算界面；
- 比牌结果直接写入结算结果。

其他 V4.4.5 规则保持不变。
