# Texas Hold'em V1.3 Complete

本版基于 V1.2 Complete，集中处理多人测试中发现的等待区、破产区、账号、排行榜、结算展示和发牌节奏问题。

## 主要修改

### 1. 全中文牌局阶段
- WAITING → 等待开始
- PREFLOP → 翻牌前
- FLOP → 翻牌
- TURN → 转牌
- RIVER → 河牌
- D / SB / BB 在牌桌上改为：庄家 / 小盲 / 大盲
- ALL-IN 保留为德州常用术语

### 2. 等候区与破产区彻底分开
- 游戏中途加入：进入“等候区”
- 本局结束后，如果有空位，等候区玩家进入正式玩家队列
- 筹码 <= 0：本局结束时立即进入“破产区”
- 破产玩家不会再被当作普通等待玩家自动入座
- 破产玩家不会参与下一局、不会准备

### 3. 昵称账号数据
房间内新增按昵称保存的账号记录：
- 筹码
- 上一局筹码变化
- 是否破产 / 破产时间
- 玩家 token

因此：
- 退出房间再用同一房间号 + 同一昵称进入，不会重新获得 1500
- 破产后退出再进入，仍然是破产账号
- 45 秒超时从当前在线列表移除后，昵称账号数据仍保留
- 同名在线时仍禁止第二个设备同时占用

说明：与当前炸金花项目一样，这是服务器进程内的房间数据；如果整个 Node 服务器重启，房间本身也会消失。

### 4. 准备状态
等待阶段所有正式玩家都显示：
- 已准备
- 未准备
房主仍然自动准备。

### 5. 排行榜重做
排行榜来自“所有曾进入过这个房间的昵称账号”，不只统计当前在线玩家。

正常玩家：
1. 玩家名  当前筹码  +/−上局变化
2. ...
按当前筹码从高到低排名。

破产玩家单独显示：
破产者：
玩家名  0  -XXXX
玩家名  0  -XXXX

破产玩家不显示排名数字，按破产时间先后排列。

### 6. 上局筹码变化
- 等待阶段玩家卡片显示“上局：+X / -X”
- 排行榜显示 +/−
- 结算界面不再显示“本局投入”
- 结算界面显示：
  - 本局筹码变化 +/−
  - 当前筹码

### 7. 等候/破产玩家不阻塞结算
只有本局实际参与、仍未破产、在线且非托管的玩家需要确认结算。
- 等候区：无需确认
- 破产区：无需确认
- 托管/掉线：无需确认

### 8. 公共牌增加发牌节奏
公共牌不再瞬间全部出现。

默认节奏：
- 同一阶段连续发牌间隔约 450 ms
- 一个阶段发完后停约 1200 ms

Flop：
第1张 → 450ms → 第2张 → 450ms → 第3张 → 1200ms

Turn / River：
发出单张牌后直接使用较长的 1200ms 阶段停顿，不再额外叠加 450ms。

多人 ALL-IN 后也按照：
翻牌 3 张 → 转牌 1 张 → 河牌 1 张
逐阶段动画发完，然后才进入摊牌结算。

### 9. 摊牌结算优化
如果通过摊牌决定胜负：
- 胜者玩家框使用蓝色边框
- 胜者最终最佳 5 张牌用金色描边
- 对应的公共牌也用金色描边
- 显示牌型名称
- 平局/多个边池可同时存在多个胜者

### 10. 其他人全部弃牌时：赢家选择亮牌
如果并非摊牌，而是其余玩家全部弃牌：
- 赢家先看到：
  - 不亮牌
  - 亮牌
- 选择亮牌：其他人结算时可以看到赢家底牌
- 选择不亮牌：其他人继续看到牌背
- 两种情况下赢家都使用蓝色胜者框
- 这种获胜不标最佳 5 张牌，因为没有必要进行最终摊牌比较

### 11. 自己的牌桌卡片更明显
自己的玩家卡片背景与其他玩家不同。
轮到自己行动时，再额外出现黄色行动边框。

### 12. 上局结果按钮
排行榜旁新增“上局结果”：
- 内容与上一局结算界面一致
- 不需要确认
- 可以随时关闭
- 仍遵守上一局的亮牌/隐藏牌规则

## 保持规则
- 初始筹码 1500
- 2–6 人正式座位
- 每 3 局提升盲注
- 10/20 → 15/30 → 20/40 → 25/50 → 30/60 → 40/80 → 50/100 → 60/120 → 75/150 → 100/200 → 125/250 → 150/300 封顶
- 跟注金额 >= 自己剩余筹码时自动 ALL-IN
- 加注拉满全部筹码时自动 ALL-IN
- 主池 / 多边池
- 45 秒重连与托管
- 系统生成 5 位房间号

## 建议重点测试
1. 破产玩家在结算出现时是否已经从正式玩家队列移到破产区。
2. 中途加入者是否始终处于等候区，结算后有空位才入座。
3. 破产者退出再用同名加入，是否仍为 0 筹码并留在破产区。
4. 等待阶段其他人的已准备/未准备是否可见。
5. 排行榜是否包含已经退出但曾进入过房间的昵称。
6. 排行榜是否显示每人的上局 +/−。
7. 破产者是否无排名数字并按破产顺序排列。
8. Flop/Turn/River 的发牌停顿是否自然。
9. 多人 ALL-IN 后是否仍按 3+1+1 动画发公共牌。
10. 摊牌胜者是否蓝框，最佳 5 张是否金框。
11. 全员弃牌时赢家是否能选择亮牌/不亮牌。
12. 等候区和破产区玩家是否不需要确认结算。
13. “上局结果”是否能重复查看且无需确认。
